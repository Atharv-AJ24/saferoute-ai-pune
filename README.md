# 🚦 SafeRoute AI – Smart Road Safety System (Pune)

## 🧠 Problem

Road accidents in India are a major issue, especially in cities like Pune.
People lack real-time insights about:

* Accident-prone zones
* Unsafe travel times
* Dynamic risk conditions

This leads to poor route decisions and increased danger.

---

## 💡 Solution

**SafeRoute AI** is an intelligent road safety system that:

* Analyzes risk levels across locations
* Provides real-time safety insights
* Helps users choose safer routes

---

## 🚀 Key Features

### 📍 Risk Map

* Visual map of Pune showing high-risk zones
* Color-coded safety indicators

### 📊 Hourly Risk Analysis

* Shows how risk changes throughout the day
* Helps avoid dangerous travel timings

### 🚨 Live Incident Ticker

* Displays real-time reported incidents
* Keeps users aware of nearby risks

### 📝 Incident Reporting System

* Users can report accidents or hazards
* Crowdsourced safety intelligence

### 🟢 Risk Badge System

* Simple safety indicators (Low / Medium / High)

---

## 🛠 Tech Stack
